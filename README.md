# 入党积极分子 · 党校刷题

电气学院分党校入党积极分子培训题库在线练习，纯静态单页应用，无需后端。

在线地址：<https://jjjkk-oss.github.io/Rudang-Quiz/>

## 题库

题库整理自《电气学院分党校积极分子》培训资料 PDF，共 **402 题**：

| 题型 | 数量 | 说明 |
| --- | --- | --- |
| 填空题 | 145 | 点击“查看答案”后自评对错 |
| 单选题 | 80 | 自动判分 |
| 多选题 | 32 | 全对才计分，少选多选不给分 |
| 判断题 | 67 | 自动判分 |
| 练习提升 | 78 | 原题库未附答案，作答后自评 |

## 功能

- **五种练习模式**：顺序刷题、随机刷题、只刷错题、错题本、模拟考试（随机 30 题）
- **自动记忆进度**：各题库独立保存当前题号，关掉页面再打开可继续
- **错题本**：做错的题自动收录，可标记“已掌握”，支持重做
- **模拟考试**：选择判断自动批改并计分，填空题给出参考答案自评
- **导入导出**：学习记录可导出为 JSON 备份，换设备后导入恢复
- **夜间模式**：深色主题，夜间刷题不刺眼
- **键盘操作**：左右方向键切换上一题 / 下一题

## 数据存储

所有学习记录保存在浏览器 `localStorage`，键名为 `rudang_quiz_v1`。
清除浏览器数据或更换设备会丢失，建议定期用“导出记录”备份。

## 本地运行

不需要构建步骤，直接用浏览器打开 `index.html` 即可。
如需通过 HTTP 访问：

```bash
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```

## 部署

仓库为纯静态站点，`index.html` 单文件包含全部样式、脚本与题库。

1. 仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `main`，目录选择 `/ (root)`
4. 保存后等待约 1 分钟即可访问
